# ChatGPT 流畅助手

用于 Chrome / Edge 的 Manifest V3 扩展。通过独立的轻量阅读层、输入草稿和后台历史补齐，减少长对话加载与回答生成时的重复处理。

当前版本：**0.14.4**。支持 `chatgpt.com` 和 `chat.openai.com`，最低 Chrome 120。

## 下载与安装

1. 从 [Releases](https://github.com/vialoyed-ctrl/chatgpt-smooth-assistant/releases/latest) 下载插件 ZIP，解压到固定目录。
2. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`，启用开发者模式。
3. 选择“加载已解压的扩展程序”，选中含 `manifest.json` 的文件夹。
4. 刷新 ChatGPT，只启用一份流畅助手。

也可以下载仓库源码，加载其中的 `extension/` 目录。更新已有安装时，先保存未发送的草稿和附件，再完整替换文件，在扩展管理页点击“重新加载”，最后刷新网页。

本仓库提供手动加载的扩展，不是 Chrome / Edge 扩展商店安装页。

## 功能

- 最新消息优先显示，较早历史在后台逐步补齐。
- 回答生成时优先处理变化的消息，延后旧消息的精细排版和历史扫描。
- 独立输入草稿、中文输入法保护、多格式附件，以及按提问定位的目录。
- 保留数学公式、代码、表格及复制功能。
- 复用消息原生工具，并处理原生菜单、弹窗和二级菜单的显示。
- AI Exporter 集成依赖用户另行安装对应第三方扩展，本仓库不包含该扩展。

## 当前版本修复

- 统一比较 URL 编码的临时分支 ID 与页面标记，修复临时分支正文和输入框识别失败。
- 后台测量保留原正文的布局尺寸，同时隐藏其绘制，避免原文漏入顶部导航区。
- 新对话尚未准备好时，不以空白阅读层遮住原页面；身份标记提交后恢复轻量阅读。
- 保留此前的菜单层级修复、二级菜单接续及生成/加载调度优化。

## 数据与权限

- 声明的扩展权限为 `storage`、`activeTab`；内容脚本只匹配上述 ChatGPT 域名。
- 扩展设置保存在浏览器本地；正文缓存及轻量草稿保留在当前标签页内存中，刷新或关闭会释放。
- 没有新增聊天上传服务或远程脚本。发送消息、提交附件以及主动操作第三方工具仍使用网站及对应工具的正常流程。

## 开发与验证

使用 Node.js 22 或更新版本：

```sh
npm ci
npm run check
npm test
npm run build
```

`npm run build` 在 `dist/` 中生成可加载的扩展目录；手动加载时选择其中含 `manifest.json` 的目录。测试依赖不进入扩展包。

目前 **145 项合成 DOM 回归通过**。另在独立 Chrome 的本地合成页面验证了 **7 项显示与点击场景**。这些检查不等同于所有在线 ChatGPT 页面验收，也没有在用户账户执行真实分支创建。完整范围见 [验证说明](docs/validation.md)。不能承诺消除所有页面卡顿；网站结构变化也可能影响兼容性。

可选浏览器检查：`node tests/browser-smoke.cjs --label local`。该脚本使用本机 Chrome、独立临时 profile 和本地 HTTP 页面；Chrome 路径可按本机安装位置调整。它采用无浏览器沙箱的本地测试模式，仅用于固定合成页面，请勿用于访问外部站点。输出的截图、日志和 profile 已在 Git 忽略规则中排除。
